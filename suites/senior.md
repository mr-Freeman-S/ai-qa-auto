# Регресс: Старший тимадмин (senior)

Фокус роли: Ветка «старший тимадмин»: свои и назначенные команды/группы. Для разделов только сисадмина (Каналы, Поля, Настройки) проверяется ОТСУТСТВИЕ доступа, в т.ч. по прямой ссылке. Для ACC/SR/EU/AFD — проверяется эффект настроек, сделанных сисадмином, глазами этой роли.

Кейсов: 84; проверок с учётом таблиц GRID: 92.
Таблицы GRID: Пользователи, Команды, Формы, Ответы, ПО.

Общие проверки закреплены за sysadmin: DISP-03, DISP-04, GRID-02, GRID-03, GRID-04, GRID-05, GRID-06, GRID-07, GRID-08, GRID-09, GRID-10, USR-03, TEAM-03, FRM-02, FRM-04, FBUILD-03, PP-05.
Они исключены из этого набора, а не пройдены под этой ролью. Для полного регресса нужен также набор владельца.
В оставшихся кейсах проверяй условия своей роли; общую механику, вынесенную владельцу, не повторяй.
