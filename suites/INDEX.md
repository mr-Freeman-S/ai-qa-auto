# Наборы регресса по ролям

| Роль | Команда | Кейсов | Проверок (с GRID × таблицы) |
| --- | --- | --- | --- |
| Сисадмин | `/regress_sysadmin` | 123 | 178 |
| Старший тимадмин | `/regress_senior` | 84 | 92 |
| Тимадмин | `/regress_teamadmin` | 80 | 88 |
| Мембер | `/regress_member` | 20 | 20 |

Распределение задаётся в roles.json; после правки — `node qa.mjs split`.
Общие проверки sharedChecks выполняются только владельцем (sysadmin); остальные наборы дополняют его ролевыми проверками. Исключение дубля не означает PASS другой роли.
