# Таблица «Поля»

Доступна только сисадмину, старший тимадмин и тимадмин — не видят и не открывают по прямой ссылке. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] FLD-09 | Объединение полей | **Шаги:** таблица «Поля» → чекбокс → «Добавить в справочник» или таблица «Поля» → кебаб → «Открыть поле» → «Добавить в справочник» (у локальных) или таблица «Поля» → кебаб → «Открыть поле» → «Объединить с…» (у справочных).**Ожидаемо:** перенос только одинаковых типов (селекты только по одному). - для не селектов из локального в справочник: выбор справочного поля для объединения, либо перенос без объединения; - для не селектов со страницы справочного поля: выбор локального поля; - для селектов из локального в справочник: выбор справочного поля для объединения с сопоставлением вариантов (+ архивация и создание варианта), либо перенос без объединения; - для селектов со страницы справочного поля: выбор локального поля с сопоставлением вариантов (+ архивация и создание варианта). |
