# «Настройки» → «Старшие тимадмины»

«Настройки» (иконка шестеренке в хедере плагина) доступны только сисадмину. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] SR-03 | Тумблер на группу vs отдельная команда | **Шаги:** «Настройки» → «Старшие тимадмины» → карточка старшего тимадмина.**Ожидаемо:** галочка у группы / команды = видимость всех сущностей группы во всех статусах; тумблер у группы = право редактировать ее формы + управлять кандидатами; доступ по отдельной команде/группе без тумблера = только видимость; изменения отражаются сразу. Применяется только по кнопке «Сохранить». |
