# «Настройки» → «Внешние пользователи»

«Настройки» (иконка шестеренке в хедере плагина) доступны только сисадмину. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] EU-02 | Назначение доступа к внешнему пользователю | **Шаги:** «Настройки» → «Внешние пользователи» → клик на блок внешнего пользователя. **Ожидаемо:** поиск по пользователям с доступом к плагину; галочка сохраняет доступ; у назначенного пользователя внешний пользователь появляется в таблице. |
