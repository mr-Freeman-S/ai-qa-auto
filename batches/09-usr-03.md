# Таблица «Пользователи»



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] USR-07 | Сброс пароля внутреннему пользователю | **Шаги:** таблица «Пользователи» → кебаб → «Настройки» → «Сброс пароля».**Ожидаемо:** выбор команды не требуется; тип/доступы не пересобираются; права:  - сисадмин: любому; - тимадмин: мемберам своей команды;  - старший тимадмин: мемберам и тимадминам своей команды / назначенных команд; - мембер: нет доступа к плагину и вкладкам (табам) по прямым ссылкам. |
| * [ ] USR-08 | Ссылки на System Console | **Ожидаемо:** - сисадмин: имя и чипы команд — ссылки на консоль; - тимадмин и старший тимадмин: имя — ссылок нет, чипы команд — ссылки на консоль. |
| * [ ] USR-09 | Попап «Список команд пользователя» | **Ожидаемо:** поиск; архивные команды с пометкой; пустое состояние «Команд нет». |
