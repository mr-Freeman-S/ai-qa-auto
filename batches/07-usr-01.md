# Таблица «Пользователи»



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] USR-01 | Видимость по ролям | **Ожидаемо:** - сисадмин: все, кроме ботов; - тимадмин: мемберы своих команд + назначенные или созданные внешние пользователи; - старший тимадмин: мемберы и тимадминов своих и назначенных команд + назначенные или созданные внешние пользователи; - мембер: нет доступа к плагину и вкладкам (табам) по прямым ссылкам. |
| * [ ] USR-02 | Создание внешнего пользователя | **Шаги:** таблица «Пользователи» → «+» → email/username/имя/фамилия.**Ожидаемо:** создан активированным, тип «внешний»; автор добавлен в список доступа; строка появляется без обновления страницы. |
| * [ ] USR-03 | Негатив создания внешнего пользователя | **Ожидаемо:** занятый email/username → ошибка с указанием поля; обязательны username + email + имя. |
