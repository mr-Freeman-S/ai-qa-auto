# Список форм



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] FRM-01 | Колонки списка | **Шаги:** плагин → «Формы».**Ожидаемо:** Название, Тип (задание / отчет), Прикрепленная форма-отчет, Политика оплаты, Описание, Автор (сисадмин), Группа команд (сисадмин, попап с поиском), Обновлено, Статус. |
| * [ ] FRM-02 | Переключатель типа Без группировки /Задание / Отчет | **Шаги:** плагин → «Формы» → группировка → «По парам». **Ожидаемо:** переключатель над списком; группировка пар задание–отчет (вложенные строки); в режиме Задание вложен ≤1 отчет, в режиме Отчет — задания 1:N. |
| * [ ] FRM-03 | Действия из строки | **Шаги:** плагин → «Формы» → кебаб.**Ожидаемо:**  - «Архивировать форму» (для не архивной формы) — у всех пользователей с доступом к плагину;  - «Восстановить форму» (для архивной формы) — у всех пользователей с доступом к плагину;  - «Копировать ссылку на заполнение формы» (для опубликованной формы) — у всех пользователей с доступом к плагину;  - «Удалить форму безвозвратно» (для архивной формы) — сисадмина (доступно, если по форме нет ответов); |
