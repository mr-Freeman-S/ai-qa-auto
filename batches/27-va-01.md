# «Посмотреть как»

Режим доступен только у сисадмина.

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] VA-01 | Вход в режим | **Шаги:** «Настройки» → «Старшие тимадмины» → иконка глазика.**Ожидаемо:** данные таблиц подменяются на данные выбранного старшего тимадмина. |
| * [ ] VA-02 | Только просмотр | **Ожидаемо:** любые действия (правка полей, создание колонок, активация/деактивация) выполняются от лица сисадмина, не просматриваемого. |
| * [ ] VA-03 | Внешние по доступу | **Ожидаемо:** видны только внешние, к кому у просматриваемого старшего тимадмина есть доступ. |
