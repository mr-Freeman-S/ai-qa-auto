# Страница формы / конструктор



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] FBUILD-01 | Шапка формы | **Ожидаемо:**  - для сисадмина: Название, Описание, «Доступно группам» (чипы + карандаш → модалка), «Тип шаблона» (неизменяем), «Форма-отчет» (прикрепление/открепление ×), блок «Расчет оплаты». - для старшего тимадмина / тимадмина: Название, Описание, «Тип шаблона» (неизменяем), «Форма-отчет» (прикрепление/открепление ×). |
| * [ ] FBUILD-02 | Типы полей | **Шаги:** форма → «+» .**Ожидаемо:** модальное окно с двумя табами («Из справочника» / «Создать новое». - для сисадмина: в табе «Из справочника» отображаются все активные справочные поля;  - для старшего тимадмина / тимадмина отображаются справочные поля с доступом на добавление в форму.  Типы нового (локального) поля: Текст, Число, Булево, Дата/время, Файл (≤4 МБ), Сингл-селект (список/кнопки), Мульти-селект (список/кнопки), Пользователь (недоступен для форм-отчетов). |
| * [ ] FBUILD-03 | Поля в канве | **Ожидаемо:** справочное (бейдж «Из справочника») — меняются только обязательность и порядок; локальное — еще название и варианты; «Убрать из формы»; «+» (из справочника / создать новое → локальное); drag порядка полей и вариантов. |
