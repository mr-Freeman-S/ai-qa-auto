# «Настройки» → «Группы команд»

«Настройки» (иконка шестеренке в хедере плагина) доступны только сисадмину. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] TG-04 | Поле «Группа команды» (из таблицы «Команды») | **Ожидаемо:** мультиселект в таблице Команды; создается автоматически; опшены (=группы) меняет только сисадмин; переименование/удаление самого поля недоступно; фильтр/сортировка/группировка работают. |
| * [ ] TG-05 | Привязка формы к группе | **Ожидаемо:** поле «Группа команд» в канвасе видит и меняет только сисадмин; фильтр списка форм по группе — только сисадмин. |
| * [ ] TG-06 | Видимость по группе | **Ожидаемо:** форма без группы — только автор и сисадмин; тимадмин — формы групп его команд; старший тимадмин — опубликованные групп его + назначенных команд; сисадмин — все. |
