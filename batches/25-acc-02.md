# «Настройки» → «Доступ к полям»

«Настройки» (иконка шестеренке в хедере плагина) доступны только сисадмину. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] ACC-04 | Возможные уровни по полям | **Ожидаемо:** системные (Имя, Email, ID, Тип пользователя) — максимум «Чтение»; Каналы и Группа команды — только сисадмина. |
| * [ ] ACC-05 | Новое справочное поле | **Ожидаемо:** «Нет доступа» всем старшим тимадминам и тимадминам; у сисадмина видно и редактируемо; видимость «для добавления в форму» — отдельная настройка, не выводится из уровней таблиц. |
| * [ ] ACC-06 | Снятие доступа | **Ожидаемо:** Чтение → Нет доступа — у старшего тимадмина / тимадмина после обновления страницы колонка пропадает, персональные настройки грида не ломаются. |
