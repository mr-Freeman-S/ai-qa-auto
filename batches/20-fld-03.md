# Таблица «Поля»

Доступна только сисадмину, старший тимадмин и тимадмин — не видят и не открывают по прямой ссылке. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] FLD-07 | Массовое добавление вариантов справочного поля | **Шаги:** таблица «Поля» → нажать на справочное поле («Источник»  — «Справочник») → «Добавить варианты списком» или таблица «Поля» → кебаб → «Открыть поле» → «Добавить варианты списком».**Ожидаемо:** дедуп в пачке и против существующих; сводка «Добавлено N, пропущено дублей M». |
| * [ ] FLD-08 | Доступ для добавления справочного поля в форму | **Шаги:** таблица «Поля» → нажать на справочное поле («Источник» — «Справочник») → «Доступ» или таблица «Поля» → кебаб → «Открыть поле» → «Доступ».**Ожидаемо:** раздел настроек (шестеренка → «Доступ к полям из справочника») — галочка + тулбар в карточке справочного поля; старший тимадмин и тимадмин в пикере полей в создании / редактировании формы — только видимые активные (у сисадмина видимые и невидимые, но только активные); снятие видимости у используемого → информирующее окно (поле остается в формах, в новые не добавить). |
| * [ ] FLD-09 | Объединение полей | **Шаги:** таблица «Поля» → чекбокс → «Добавить в справочник» или таблица «Поля» → кебаб → «Открыть поле» → «Добавить в справочник» (у локальных) или таблица «Поля» → кебаб → «Открыть поле» → «Объединить с…» (у справочных).**Ожидаемо:** перенос только одинаковых типов (селекты только по одному). - для не селектов из локального в справочник: выбор справочного поля для объединения, либо перенос без объединения; - для не селектов со страницы справочного поля: выбор локального поля; - для селектов из локального в справочник: выбор справочного поля для объединения с сопоставлением вариантов (+ архивация и создание варианта), либо перенос без объединения; - для селектов со страницы справочного поля: выбор локального поля с сопоставлением вариантов (+ архивация и создание варианта). |
