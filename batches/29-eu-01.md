# «Настройки» → «Внешние пользователи»

«Настройки» (иконка шестеренке в хедере плагина) доступны только сисадмину. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] EU-01 | Отображение | **Шаги:** «Настройки» → «Внешние пользователи».**Ожидаемо:** на странице отображаются внешние пользователи с отображением доступа пользователей к ним; поиск ищет только по внешним пользователям. |
| * [ ] EU-02 | Назначение доступа к внешнему пользователю | **Шаги:** «Настройки» → «Внешние пользователи» → клик на блок внешнего пользователя. **Ожидаемо:** поиск по пользователям с доступом к плагину; галочка сохраняет доступ; у назначенного пользователя внешний пользователь появляется в таблице. |
| * [ ] EU-03 | Снятие доступа к внешнему пользователю | **Шаги:** «Настройки» → «Внешние пользователи» → клик на блок внешнего пользователя. **Ожидаемо:** у назначенного пользователя внешний пользователь пропадает из таблицы. |
