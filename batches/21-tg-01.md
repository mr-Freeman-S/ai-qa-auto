# «Настройки» → «Группы команд»

«Настройки» (иконка шестеренке в хедере плагина) доступны только сисадмину. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] TG-01 | Доступ к управлению | **Шаги:** «Настройки» → «Группы команд».**Ожидаемо:** «Настройки» видит только сисадмин, остальные не имеют доступ по прямым ссылкам. |
| * [ ] TG-02 | CRUD группы | **Шаги:** «Настройки» → «Группы команд».**Ожидаемо:** создать (мультиселект команд), переименовать, изменить состав, удалить; в карточке — нередактируемый список старших с доступом на группу + переход в «Старшие тимадмины». |
| * [ ] TG-03 | Удаление группы — каскад | **Шаги:** «Настройки» → «Группы команд» → иконка удаления.**Ожидаемо:** модалка-превью (какие формы/ПО теряют видимость, какие снимаются с публикации); необратимо; после удаления группа исчезает из поля у всех форм/ПО и из мультиселекта. |
