# Политика оплат



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] PP-04 | Кандидат (правка активной) | **Ожидаемо:** правка активной ПО автором создает кандидата (действующая версия и расчеты не меняются); сисадмин без кандидата правит сразу, с кандидатом — заблокировано; шапка «Есть правки на проверке» / «Черновик правок» видна автору и сисадмину, группам — нет. |
| * [ ] PP-05 | Расчет | **Ожидаемо:** секция «Оплата» в карточке ответа формы; состояния Не рассчитано / Предупреждение / Рассчитано; расшифровка — снимок; перерасчет создает новую запись, прошлые не пересчитываются; неучаствующий компонент не блокирует (надбавка 0). |
| * [ ] PP-06 | Блокировка расчета | **Ожидаемо:** форма не опубликована / ПО не активна / неподтвержденный маппинг → блок; снятие сисадмином (перематчить или «Оставить как есть»). |
