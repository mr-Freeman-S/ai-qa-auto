# Таблица «Каналы»

Доступна только сисадмину, старший тимадмин и тимадмин — не видят и не открывают по прямой ссылке. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] CHAN-04 | Принудительный перенос канала | **Предусловия:** в канале есть участники не из целевой команды. **Ожидаемо:** без force — блок со списком; force → лишние удаляются, в ответе список удаленных; деактивированные удаляются; системное сообщение «Канал перенесен…». |
| * [ ] CHAN-05 | Граничные переносы канала | **Ожидаемо:** одноименный канал в целевой → ошибка; архивные каналы — перенос недоступен; town-square/off-topic переносятся только если нет одноименного. |
| * [ ] CHAN-06 | Колонки | **Ожидаемо:** Название, Тип (Публичный/Закрытый), Команда (ссылка в System Console), Участники канала (попап с поиском), Статус (Активен/Архив), Системный (Да/Нет). |
