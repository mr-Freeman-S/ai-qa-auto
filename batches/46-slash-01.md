# Слэш-команды



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] SLASH-01 | /form submit | **Ожидаемо:** диалог выбора формы (только опубликованные, без ID); сообщение со списком удаляется после выбора → диалог с полями; ответ идентичен вебу (валидация, запись, единый формат). |
| * [ ] SLASH-02 | Типы полей в диалоге | **Ожидаемо:** текст / число / bool /дата (YYYY-MM-DD) / пользователь (из формы) / сингл селект (только десктоп); мульти селект (только десктоп). |
| * [ ] SLASH-03 | /form reports | **Ожидаемо:** фильтры количество (число, дефолт 20) / форма / пользователь → таблица «only for you». |
