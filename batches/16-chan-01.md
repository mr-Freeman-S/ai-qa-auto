# Таблица «Каналы»

Доступна только сисадмину, старший тимадмин и тимадмин — не видят и не открывают по прямой ссылке. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] CHAN-01 | Видимость таблицы | **Ожидаемо:** вкладку и данные видит только сисадмин; содержимое не зависит от его команд — видны каналы всех команд. |
| * [ ] CHAN-02 | Перенос канала — проверка участников | **Шаги:** таблица «Каналы» → кебаб → «Перенести в другую команду» → выбрать команду (текущая недоступна) → «Проверить». **Ожидаемо:** если все участники канала состоят в целевой — переход к шагу «Перенос»; иначе — список «лишних» + опция принудительного удаления участников из канала. |
| * [ ] CHAN-03 | Перенос канала — выполнение | **Шаги:** таблица «Каналы» → кебаб → «Перенести в другую команду» → выбрать команду (текущая недоступна) → «Проверить» → «Перенести».**Ожидаемо:** канал в целевой команде; тост; строка перемещается между группами без обновления страницы |
