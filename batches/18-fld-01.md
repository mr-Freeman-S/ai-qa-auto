# Таблица «Поля»

Доступна только сисадмину, старший тимадмин и тимадмин — не видят и не открывают по прямой ссылке. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] FLD-01 | Видимость таблицы | **Ожидаемо:** таблицу «Поля» видит только сисадмин, остальные не имеют доступ по прямым ссылкам. |
| * [ ] FLD-02 | Создание справочного поля | **Шаги:** таблица «Поля» → «+».**Ожидаемо:** название/описание/тип; для селекта — варианты (по одному и массово) + режим (список/кнопки); тулбар «Доступ для добавления в форму» (дефолт выкл). |
| * [ ] FLD-03 | Негатив создания справочного поля | **Шаги:** таблица «Поля» → «+».**Ожидаемо:** селект без хотя бы одного варианта не сохраняется (создание и редактирование); занятое название → «Поле с таким названием уже есть». |
