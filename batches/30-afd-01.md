# «Настройки» → «Доступ к полям из справочника»

«Настройки» (иконка шестеренке в хедере плагина) доступны только сисадмину. 

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] AFD-01 | Отображение | **Шаги:** «Настройки» → «Доступ к полям из справочника».**Ожидаемо:** на странице отображаются справочные активные поля; опции фильтра («Видны в формах» / «Скрыты»); поиск ищет только по справочным полям; галочка у чекбокса выдает доступ на добавление поля в форму для старшего тимадмина и тимадмина (сисадмин может добавлять поля без доступа). |
| * [ ] AFD-02 | Назначение доступа на добавление в форму | **Шаги:** «Настройки» → «Доступ к полям из справочника» → чекбокс у поля.**Ожидаемо:** галочка у чекбокса выдает доступ на добавление поля в форму для старшего тимадмина и тимадмина (сисадмин может добавлять поля без доступа). |
| * [ ] AFD-03 | Снятие доступа на добавление в форму | **Шаги:** «Настройки» → «Доступ к полям из справочника» → чекбокс у поля.**Ожидаемо:** снятие галочки у чекбокса снимает доступ на добавление поля в форму для старшего тимадмина и тимадмина (сисадмин может добавлять поля без доступа); отображается предупреждение с перечислением использования поля в формах. |
