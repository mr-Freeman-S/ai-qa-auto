# Политика оплат



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] PP-01 | Жизненный цикл | **Ожидаемо:** Черновик / Ожидает проверки / Активна / Архив; переходы: «Отправить на проверку», «Активация без проверки» (сисадмин), «Одобрение», возврат на доработку, «Архивировать», «Восстановить». |
| * [ ] PP-02 | Создание | **Ожидаемо:** название (уникально глобально), опц. базовая ставка, компоненты (Верхняя/Нижняя граница, Диапазоны, Чекбокс); «на проверку» доступно только при базовой ставке или ≥1 компоненте (для не-сисадмина). |
| * [ ] PP-03 | Прикрепление к форме | **Ожидаемо:** только сисадмин, настройки формы → «Расчет оплаты»; только опубликованная форма; маппинг компонент → такого же типа поле (1 поле → 1 компонент, 1 форма → 1 ПО, 1 ПО → N форм); форма с уже прикрепленной ПО недоступна для выбора. |
