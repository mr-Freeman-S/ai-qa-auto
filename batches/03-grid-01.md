# DataGrid — общая механика списков

Общая механика списков (применять к каждой вкладке (табу): Пользователи, Команды, Каналы, Формы, Ответы, ПО)

| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] GRID-01 | Персистентность настроек | **Шаги:** задать фильтр/сортировку/скрытые колонки → релогин / другой браузер / устройство.**Ожидаемо:** настройки восстановлены; у другого пользователя — свои. |
| * [ ] GRID-02 | Первый вход без настроек | **Ожидаемо:** валидный дефолт без ошибки; недостающие поля достраиваются. |
| * [ ] GRID-03 | Фильтры по типу поля | **Ожидаемо:**  - String: содержит / не содержит, равно / не равно, пустой / не пустой; - Int= / ≠, \< / \>, ≤ / ≥, пустой / не пустой; - Date: меньше чем (до) / больше чем (после), пустой / не пустой; - Single select: равно / не равно, любой из; - Multi select: содержит хотя бы один / содержит все / не содержит, пустой / не пустой; - File: пустой / не пустой; - Bool: равен. |
