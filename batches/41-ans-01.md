# Заполнение и ответы



| ID | Тест-кейс | Детали |
| --- | --- | --- |
| * [ ] ANS-01 | Каналы заполнения | **Ожидаемо:** через плагин, `/form submit`, по ссылке из задания. |
| * [ ] ANS-02 | Правила записи | **Ожидаемо:** запись только в статусе «Опубликована»; один пользователь — несколько ответов; обязательные блокируют отправку; ответ не по ссылке не редактируется после отправки. |
| * [ ] ANS-03 | Ссылки при заполнении | **Ожидаемо:** множественный сабмит по одной ссылке с возможностью редактирования предыдущих ответов; отозванная ссылка неактивна, но ее отчеты доступны; в статусах ≠ «Опубликована» → «Ссылка временно не работает». |
